# 🎓 Gerenciador de Videoaulas

Sistema web para organizar disciplinas, aulas e temas de estudo.

## 🌐 Acesso
https://seu-usuario.github.io/videoaulas/

## ✨ Recursos
- Disciplinas → Aulas → Temas
- Múltiplos links por item
- Anotações por tema
- Modo claro e noturno
- Player do YouTube integrado
- PDF do Google Drive
- Backup automático em `.json`
